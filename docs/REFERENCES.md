The ps4debug-NG protocol describes authentication for the scan command family, with an intentionally undocumented challenge keystream. No guessed/bypassed authentication is implemented. Client-side scans use ordinary documented reads. The source's verified process-write capability 1.1 is required for writes, and the client also checks readback.

The owner's Silksong v01.04 references (section 14, offset `1B6BFED`, original `8943604883C408`, cave `4783800`) seed synthetic tests only. No v01.05 address, cave safety or actual health logic is claimed.
